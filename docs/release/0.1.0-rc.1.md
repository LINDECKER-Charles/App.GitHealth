# GitHealth `0.1.0-rc.1`

Cette première release candidate livre le parcours MVP complet pour analyser localement
les branches d'un dépôt sans le modifier.

## Points forts

- diagnostic reproductible des branches locales et de suivi distant ;
- explication des compteurs, SHA, contributeurs et politiques appliquées ;
- historique immuable, export CSV filtré et sauvegarde SQLite ;
- relocalisation d'un dépôt déplacé avec contrôle de continuité de l'historique ;
- distributions autonomes Windows et macOS, plus Docker Compose ;
- protections locales contre les requêtes inter-origines et les entrées Git hostiles ;
- benchmarks versionnés et scénario bout en bout avec contrôle de non-mutation.

## Avant de tester

GitHealth ne met jamais à jour les références distantes. Exécuter volontairement les
commandes Git habituelles si une vue récente de la forge est nécessaire. Les archives
macOS ne sont pas encore signées ni notariées.

Consulter le [guide utilisateur](../USER_GUIDE.md), le
[dépannage](../TROUBLESHOOTING.md) et les
[limites connues](../KNOWN_LIMITATIONS.md) avant une recette sur un dépôt sensible.
