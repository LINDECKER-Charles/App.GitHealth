# GitHealth `0.1.0-rc.1`

This first release candidate delivers the complete MVP journey: analysing a repository's
branches locally, without modifying it.

## Highlights

- reproducible diagnosis of local and remote-tracking branches;
- explanation of the counters, SHAs, contributors and applied policies;
- immutable history, filtered CSV export and SQLite backup;
- relocation of a moved repository with a history continuity check;
- self-contained Windows and macOS distributions, plus Docker Compose;
- local protections against cross-origin requests and hostile Git input;
- versioned benchmarks and an end-to-end scenario with a non-mutation check.

## Before testing

GitHealth never updates remote references. Run your usual Git commands deliberately if you
need a recent view of the forge. The macOS archives are not signed or notarised yet.

Read the [user guide](../USER_GUIDE.md), the
[troubleshooting guide](../TROUBLESHOOTING.md) and the
[known limitations](../KNOWN_LIMITATIONS.md) before running acceptance tests on a
sensitive repository.
