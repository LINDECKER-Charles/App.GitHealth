## What shipped

The project is published under the MIT licence — use, modification and redistribution are
free provided the copyright notice is kept — with `CITATION.cff` for citing the original
work and `THIRD-PARTY-NOTICES.md` for the redistributed components: IBM Plex fonts under
SIL OFL 1.1, Lucide glyphs under ISC.

Around it: a code of conduct, a contribution guide, a support page, a security policy,
issue and pull request templates, and code owners. The documents move out of the repository
root into `docs/` with every link rebased, and the whole public documentation, the README
visuals and the GitHub templates are written in English.

## Why

A public repository is read before it is run. The licence and the third-party notices are
what make the first reading conclusive, and the contribution framework is what makes the
second one possible.

The documents leave the root because a root full of Markdown hides the ones that must stay
there — `README.md`, `LICENSE`, `CHANGELOG.md` — behind a dozen that do not.
